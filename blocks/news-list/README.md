# news-list

Custom **news-list** block. Purpose: authored list of press releases with optional thumbnail, title link, date and Download button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional first row with one cell holding a heading (the list title); then one row per item with cells: [thumbnail image] | title link + date paragraph | [Download link]. Thumbnail and Download cells are optional and recognised by content.

## Supported variations

No variations.
