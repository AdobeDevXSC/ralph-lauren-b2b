# columns

Custom **columns** block. Purpose: side-by-side image and text; the text column is centred vertically.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each row holds the columns; a cell with only an image is an image column. Swap the cells to put the image on the right.

No variations.
