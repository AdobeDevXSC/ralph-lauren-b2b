# hero

Custom **hero** block. Purpose: full-bleed page-top banner: image with a centred white uppercase title, a muted looping background video, or an image on its own.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell (or several rows) holding: background image; title heading (h1 or h2); optional paragraphs and buttons. Video option: also a link to an .mp4 file (the image becomes the poster).

## Supported variations

| Variation | Option class |
| --- | --- |
| Video | `video` |
| Image only | `image-only` |
