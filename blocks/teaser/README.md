# teaser

Custom **teaser** block. Purpose: promotional image link with an overlaid title, optional deck text and a call to action.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row of two cells (or two rows of one cell): image | heading, optional deck paragraph(s), CTA link (bold = primary button).
