# quote

Custom **quote** block. Purpose: serif pull quote with optional attribution, or with a signature image beneath.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: quotation paragraph(s) (quote marks are added automatically); row 2 (optional): attribution text (italic text becomes a cite), or a signature image.

| --- | --- |
