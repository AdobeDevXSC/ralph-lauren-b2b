# carousel

Custom **carousel** block. Purpose: slider; default shows one slide with a text panel, brands shows a looping strip of portrait brand images with label links.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: image | content (default: heading, text, buttons; brands: one link whose text is the brand label).
